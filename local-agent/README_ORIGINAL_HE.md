# הסוכן האישי — גרסה ניידת

## עדכון במחשב הנוכחי
סגור את חלון הסוכן. שמור עותק של agent.py הישן. העתק את agent.py ואת config.json מהחבילה לתיקייה של start.bat והפעל את start.bat.
ההיסטוריה והקבצים נשארים בתיקייה הישנה: %USERPROFILE%\.personal-ai-agent
אם התקנה חדשה: הרץ בתיקיית הפרויקט `python -m pip install -r requirements.txt` ואז `python -m playwright install chromium`.

## החלפת מוח
ערוך config.json כשהסוכן סגור. ברירת המחדל היא Ollama עם qwen3:8b.
למודל Ollama אחר שנה AI_MODEL. למחשב אחר שמריץ Ollama שנה AI_BASE_URL רק דרך רשת פרטית מאובטחת.
לספק שמציע Chat Completions תואם: הגדר AI_PROVIDER ל-openai_compatible, את AI_BASE_URL לכתובת הבסיס של הספק (לרוב מסתיימת ב-/v1), ואת AI_MODEL לשם מודל התומך בממשק זה.
מפתח AI_API_KEY מוגדר במשתני הסביבה בלבד, לא ב-config.json ולא בקוד. לאחר שינוי משתני הסביבה פתח חלון הפעלה חדש.
החלפת ספק עשויה לשלוח אליו את 18 הודעות ההקשר האחרונות ואת תוצאות הכלים. אין כאן תקרת תקציב מקומית. שימוש בענן עשוי להיות בתשלום.

## מעבר למחשב אחר עם כל המידע
1. עצור את הסוכן לפני העתקה.
2. העתק את התיקייה %USERPROFILE%\.personal-ai-agent לתוך תיקיית הפרויקט בשם data. שמור גם את המקור כגיבוי.
3. הוסף ל-config.json את ההגדרה "AGENT_DATA_DIR": "data" (עם פסיק תקין בין השדות).
4. העתק את כל תיקיית הפרויקט למחשב החדש, כולל data ו-config.json.
5. התקן Python ואת התלויות במחשב החדש. התקן Ollama והורד את המודל, או הגדר חיבור לספק ענן.
6. הגדר מחדש מפתחות במשתני הסביבה והפעל start.bat. בדוק שההיסטוריה קיימת ובקש רשימת קבצים.
אין צורך להעביר סיסמאות בתוך החבילה. הנתונים עשויים להכיל מידע אישי: גבה אותם במקום פרטי. אין גיבוי אוטומטי או סנכרון מקביל בין מחשבים.

## שרת או כלי AI אחר
ניתן להריץ את תוכנת Python גם במחשב/שרת אחר עם התלויות הנדרשות. בשרת ללא מסך כלי הדפדפן דורשים התאמה נוספת.
הגרסה הזאת מאזינה רק ב-127.0.0.1. היא אינה שרת ציבורי ואינה פותחת גישה מהטלפון.
חיבור מתוך ChatGPT או כלי AI אחר דורש מתאם מתאים, אימות והרשאות; הוא אינו כלול בגרסה זו. החלפת מודל באמצעות API כבר נתמכת.
פקודות Windows, התקנות תוכנה ו-Tailscale עדיין אינם מחוברים. אישורים חלים על כלי הקבצים והדפדפן הקיימים; לפני לחיצה בדפדפן בדוק את הפעולה, כי לחיצה יכולה לשלוח טופס או לפרסם.

## מה תוקן
תוקנה שגיאת JavaScript שחסמה שליחה. נוספו הגדרות ספק/מודל/נתונים נפרדות. פעולות דפדפן נשלחות לאותו תהליך עבודה כדי למנוע מעבר בין threads. אישורים פגים לאחר עשר דקות. נחסמו בקשות מדפי אינטרנט זרים ומ-Host לא מוכר.
בדיקות החבילה משתמשות בשרת מודל מדומה; לא בוצעה בדיקה במחשב Windows שלך או במודל החי שלך.
