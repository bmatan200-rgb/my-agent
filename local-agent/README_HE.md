# הסוכן האישי + Agent Sync — גרסת חיבור מקומית

**חשוב:** הגרסה הזו מחברת את הסוכן הישן לשרת Agent Sync המקומי שכבר הפעלת.
היא **לא מחברת עדיין את ChatGPT Work** לשרת, ולא מאפשרת ל-Work להפעיל את המחשב ללא חיבור נוסף.
אין בשלב זה גיבוי ענן או סנכרון אוטומטי אל Work.

## התקנה בלי לדרוס קבצים קיימים

1. עצור את הסוכן הישן עם Ctrl+C בחלון שבו הוא פועל. השאר את חלון `node server.mjs` של `agent-sync-starter` פתוח.
2. גבה את התיקייה של הסוכן הישן ואת `%USERPROFILE%\.personal-ai-agent` (אם קיימת). אל תשלח לאף אחד קובצי גיבוי עם נתונים אישיים.
3. חלץ את `agent-connected-v1.zip` לתיקייה **חדשה ונפרדת** על שולחן העבודה. אל תדרוס את `agent-sync-starter` או את תיקיית הסוכן הישנה.
4. אם התלויות לא מותקנות, הרץ `install.bat`. אחרת אפשר לעבור ישירות להפעלה עם `start.bat`.
5. פתח את `http://127.0.0.1:8765` ולחץ על **בדוק סנכרון**.
6. אם מופיעה הודעה שהשרת מחובר, אפשר לכתוב בצ'אט: `בדוק חיבור לסנכרון`, `הצג משימות משותפות`, `זכור במשותף: שם הפרויקט = eBay`, או `משימה משותפת: לבדוק מוצר חדש`.

הזיכרון והיסטוריית השיחות הישנה ימשיכו להיקרא מהנתיב `%USERPROFILE%\.personal-ai-agent`, אלא אם הגדרת קודם `AGENT_DATA_DIR` מותאם אישית. אם הגדרת נתיב כזה בקובץ config.json הישן, העתק את **ערך ההגדרה בלבד** לחדש לפני הפעלה; אל תחליף את כל קובץ ההגדרות בלי לבדוק.

## אם בדיקת הסנכרון נכשלת

שרת הסנכרון המקומי צריך לפעול בכתובת `http://127.0.0.1:8877`.
הגרסה הזאת מחפשת אוטומטית את קובץ `private-data\token.txt` בתיקיית `agent-sync-starter` הסמוכה, או בשולחן העבודה / OneDrive.
אם לא נמצא, הוסף בתוך אובייקט ההגדרות שבקובץ `config.json` של הסוכן החדש שדה `SYNC_TOKEN_FILE` עם הנתיב המלא ל-`private-data/token.txt` (תוך שמירה על תחביר JSON תקין).

ב-Windows יש להחליף את הדוגמה בנתיב האמיתי, ולהקפיד על `\\` כפול בכל מפריד בתצורת JSON.
**אל תעתיק את תוכן token.txt לתוך הצ'אט, קוד או config.json.** ההגדרה מכילה רק נתיב לקובץ.

## הכלים שנוספו

- `shared_status`: בדיקת חיבור לסנכרון.
    - פקודות מפורשות בצ׳אט (ללא צורך בהחלטת המודל): `זכור במשותף: מפתח = ערך`, `משימה משותפת: כותרת`, `הצג משימות משותפות`.
- `shared_memory`: קריאת עד 25 זיכרונות אחרונים.
- `shared_tasks`: קריאת עד 25 משימות אחרונות.
- `shared_remember`: שמירת פריט זיכרון (דורש אישור).
- `shared_queue_task`: יצירת משימה משותפת (דורש אישור).
- `shared_complete_task`: השלמת משימה (דורש אישור).
- `browser_search`: חיפוש ביוטיוב או בגוגל בדפדפן (דורש אישור).

הוגדר `BROWSER_CHANNEL=msedge` כדי להשתמש ב-Edge אם הוא מותקן. אפשר לשנות ל-`chromium` ב-config.json. הדפדפן מופעל דרך Playwright — ולא בהכרח משתמש בפרופיל Edge הראשי שלך.

### אבטחה והגבלות

- שרת הסנכרון נשאר מקומי בלבד (`127.0.0.1:8877`). **אין לפתוח אותו לאינטרנט**.
- אין גישה אוטומטית לחשבונות Gmail, eBay או רכישות.
- פעולות כתיבה לזיכרון המשותף, פתיחת דפדפן וחיפוש בו עדיין מצריכות אישור בממשק.
- הסוכן יכול להחזיר שגיאה אם Ollama אינו פועל. לחיצה על **בדוק סנכרון** לא זקוקה ל-Ollama.
- נתוני זיכרון משותף נשמרים ללא הצפנה בתיקיית `agent-sync-starter/private-data`. שמור אותה פרטית ובצע גיבוי מאובטח.
- אם הפעלת בעבר `AGENT_REMOTE_PORT` דרך Tailscale, בדוק שוב הרשאות גישה מרחוק לפני שמירת מידע רגיש בזיכרון המשותף.

## בדיקה מקומית

```powershell
python -m py_compile agent.py shared_sync.py
```

כדי להשלים בהמשך את חיבור Work, נצטרך ליצור מתאם מורשה ונפרד; הפעלת Agent Sync לבד אינה עושה זאת.
