# שדרוג הסוכן המקומי — אישור חד־פעמי לכל גישה

## מה התווסף

- פתיחת מסמכים וקובצי מדיה נתמכים מתוך תיקייה שאושרה לפעולה הנוכחית.
- פתיחת Gmail או Outlook בחלון דפדפן נפרד. יש להתחבר ידנית במחשב; הסוכן אינו מקבל סיסמאות.
- קריאת קובץ או דף דפדפן, כולל מייל פתוח, מחייבת אישור חדש בכל פעם.
- מסך האישור אינו מציע הרשאה מתמשכת. גם הרשאות ישנות שנשמרו לקבצים אינן עוקפות אישור.
- תוכן שנקרא נשלח לספק המודל שנבחר בהגדרות הסוכן; ברירת המחדל בפרויקט היא Ollama מקומי.

## הפעלה

1. עצור את הסוכן שרץ כרגע באמצעות Ctrl+C בחלון PowerShell שלו.
2. פתח את תיקיית personal_agent_complete והפעל start.bat.
3. רענן את דף הסוכן.

## שימוש

- כדי לפתוח קובץ: בקש לפתוח את המסמך וציין את הנתיב המלא.
- כדי לחפש מסמך מחוץ לתיקיית העבודה: בקש לחפש בתיקייה. אשר את החיפוש, ואז אשר בנפרד את פתיחת הקובץ.
- חיפוש בכונן שלם מתחיל בתיקיות המשתמש, מדלג על תיקיות מערכת ומטמון, ומחזיר הודעה אם התוצאות חלקיות. לחיפוש מדויק ומהיר יותר, ציין תיקייה או שם קובץ.
- כדי לפתוח Gmail: כתוב "פתח Gmail". כדי לפתוח Outlook: כתוב "פתח Outlook".
- התחבר בעצמך בחלון הדפדפן. ייתכן שתידרש התחברות מחדש אחרי הפעלה מחדש של הסוכן.
- בכל קריאה של תוכן המייל תופיע בקשת אישור חדשה; התוכן עובר לספק המודל שנבחר.
- לחיצות ומילוי טפסים דורשים אישור לכל פעולה. שליחת מייל אינה מופעלת בגרסה הזו.

## דיבוב

הסוכן עדיין לא מחובר לכלי הדיבוב. הגרסה שנשמעה בעברית ברורה השתמשה בקול TTS חדש ולא הוכיחה שיבוט של קול האישה המקורי. נשאיר את שילוב הדיבוב כבוי עד שתיבדק ותאושר גרסת דיבוב עם קול משוכפל שאכן נשמעת טוב.

## הגנות ונתונים

קבצי הפעלה, מפתחות, סיסמאות ותיקיות מערכת נשארים חסומים. פתיחה חיצונית מוגבלת למסמכים ולמדיה נתמכים. הסוכן לא שולח מיילים, לא מוחק קבצים ולא מבצע רכישות. נתוני הצ׳אט, ההגדרות והסנכרון נשארים ללא שינוי.
