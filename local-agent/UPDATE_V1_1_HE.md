# תיקון לגרסה 1.1 — סוכן אישי

## מה תוקן

- כשל בכלי (כגון `browser_open` עם כתובת לא תקינה) מוצג ככשל אמיתי. הוא **אינו** נשלח שוב למודל כדי שימציא מה קרה.
- פקודות כגון `פתח Edge`, `פתח לי את הדפדפן Edge`, `פתח יוטיוב`, `חפש ביוטיוב את עידן רייכל`, `פתח את Edge וחפש שיר ביוטיוב` מטופלות באופן ישיר.
- נוסף כלי `browser_launch` שמפעיל דפדפן בלי לדרוש כתובת URL.
- פקודות זיכרון ריקות אינן נשלחות לשרת.
- פעולה שדורשת אישור ממשיכה לדרוש את אישור המשתמש; שגיאה לא תסומן כהצלחה.

## איך לעדכן התקנה קיימת (מומלץ)

1. סגור את הסוכן הישן בחלון שבו פועל `python agent.py` באמצעות `Ctrl+C`. אל תעצור את שרת הסנכרון `node server.mjs`.
2. בתיקיית הסוכן שבה נמצא `start.bat`, צור גיבוי של `agent.py` (למשל `agent-backup.py`).
3. העתק **רק** את קובץ `agent.py` מהגרסה החדשה לתיקייה הזו. אשר החלפה של הקובץ האחד הזה בלבד.
4. השאר את `config.json`, `shared_sync.py`, התיקייה `agent-sync-starter` ונתוני `%USERPROFILE%\\.personal-ai-agent` כמו שהם.
5. הפעל שוב `start.bat` ורענן את הדף.

אפשר גם לחלץ את כל ZIP הגרסה הזו לתיקייה חדשה, במקום להחליף קובץ; במקרה כזה אל תעביר או תדרוס נתונים אישיים או מפתחות.

## בדיקת שמירת זיכרון

כתוב לסוכן:

    זכור במשותף: שם הפרויקט = הסוכן האישי שלי

אשר את פעולת `shared_remember`. התשובה הצפויה כוללת `הזיכרון המשותף נשמר בהצלחה`.
לחץ על `בדוק סנכרון`: המספר **זיכרונות** אמור להיות 1 לפחות. אם נשאר 0, השמירה לא הושלמה. לאחר מכן אפשר לכתוב `הצג זיכרון משותף`.

## בדיקת Edge

כתוב `פתח Edge` ואשר. אם Microsoft Edge מותקן וזמין ל-Playwright, אמור להיפתח חלון. אפשר לבדוק גם `חפש ביוטיוב את עידן רייכל` (דורש אישור נפרד).

> בדיקת הקוד שנערכה בסביבת הבנייה בדקה ניתוב פקודות ותוצאות אישור. הפעלה בפועל של Edge במחשב ה-Windows שלך עדיין טעונה בדיקה אצלך.

## מצב החיבור ל-ChatGPT Work

שרת Agent Sync מחבר כרגע את הסוכן המקומי לזיכרון מקומי; הוא עדיין **לא** מסנכרן אוטומטית עם ChatGPT Work.
